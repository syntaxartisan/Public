# Projects

This folder contains various software projects I've built.

## GroupSort

A C# project for experimenting with and comparing sorting approaches.

## OperationsKnowledge

An ASP.NET Core Web API for managing operational systems, their owners, and related organizational information. The project demonstrates backend development using Entity Framework Core, SQL Server, authentication, authorization, DTOs, service-layer architecture, and automated testing.

## OperationsKnowledge.Tests

Automated unit and integration tests for the OperationsKnowledge API.

## OperationsKnowledge.TokenGenerator

A small console application used to generate JWT access tokens for testing the OperationsKnowledge API's authentication and authorization features.
